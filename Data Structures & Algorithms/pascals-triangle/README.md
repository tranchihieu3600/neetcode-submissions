## Pascal's Triangle

**Độ khó:** Easy

---

You are given an integer `numRows`.



Return the first `numRows` of **Pascal&#39;s triangle**.



In **Pascal&#39;s triangle**, each number is the sum of the two numbers directly above it and the first and last number on each row must be equal to 1, as shown below:



 


Example 1:**


```
**Input:** numRows = 5
**Output:** [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]

```
Example 2:**


```
**Input:** numRows = 1
**Output:** [[1]]

```

 


**Constraints:**





	- `1 <= numRows <= 30`
